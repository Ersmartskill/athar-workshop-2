# أثَر — مهمة الورشة الثانية

أضيفت صفحة مستقلة `about.html`، مع رابط من الرئيسية وإليها، ودعم PWA: manifest وأيقونات PNG وservice worker وتخزين للصفحات دون اتصال وزر تثبيت وإرشادات Safari.

## فتح المشروع في OpenCode Desktop
1. فك ضغط الحزمة على الحاسوب.
2. افتح مجلد `ATHAR_workshop2` في OpenCode Desktop؛ هو المجلد الذي يحتوي `package.json`.
3. اطلب من OpenCode فحص متطلبات المهمة وتشغيل `npm run check` و`npm test` ثم `npm run build`.
4. إذا احتاج Node.js فثبّت إصدار LTS مدعومًا ثم أعد فتح البرنامج.
5. للمعاينة عبر localhost: نفّذ `npm run build` ثم `npm run preview` لعرض مجلد `dist` على `http://localhost:4173`. لا تختبر PWA بالنقر المزدوج على index.html.

## النشر السهل يدويًا على GitHub Pages
1. أنشئ مستودعًا جديدًا باسم `athar-workshop-2`، عامًا إن كنت تستخدم خطة GitHub المجانية.
2. اختر Add file ثم Upload files.
3. ارفع **محتويات** مجلد `dist`، بما فيها مجلد `assets`؛ يجب أن يظهر `index.html` في جذر المستودع، وليس داخل dist أو مجلد آخر. لا ترفع ZIP نفسه.
4. احفظ عبر Commit changes.
5. Settings > Pages > Build and deployment > Source: Deploy from a branch.
6. Branch: main، والمجلد: /(root)، ثم Save.
7. عند اكتمال النشر افتح الرابط الذي تعرضه GitHub Pages.

## بديل: نشر المصدر باستخدام Actions
ارفع كامل محتويات المشروع بما فيها `.github/workflows/pages.yml`، واختر Settings > Pages > Source: GitHub Actions. يبدأ النشر عند الدفع إلى main ويمكن تشغيله يدويًا أيضًا. يفحص workflow المصدر ويشغّل اختبارات التطبيق والبناء قبل النشر. لا تخلط هذا المسار مع رفع dist فقط.

## التحقق والتسليم
- افتح الموقع وانقر «عن أثَر»: يجب أن ينتقل إلى عنوان ينتهي بـ about.html، ثم ارجع للرئيسية.
- جرّب البحث والتحديات.
- آيفون: افتح رابط النشر في Safari > المشاركة > إضافة إلى الشاشة الرئيسية > إضافة.
- أندرويد: Chrome > تثبيت أثَر، أو قائمة المتصفح > تثبيت التطبيق/إضافة إلى الشاشة الرئيسية بحسب الجهاز.
- انتظر رسالة «جاهز للعمل دون اتصال» ثم اقطع الإنترنت وأعد فتح التطبيق والرئيسية وصفحة عن أثَر.
- أعد الإنترنت قبل إرسال رابط الرئيسية ورابط about.html. احتفظ بصور توضح الصفحة الفرعية وأيقونة التطبيق إذا طلبتها جهة الورشة.
- موعد الرسالة: السبت القادم، 24 أكتوبر 2026، الساعة 10 مساءً بتوقيت السعودية، ما لم تصدر الجهة موعدًا مختلفًا.

## ما نُفّذ وما بقي
نجحت فحوص صياغة JavaScript وروابط الصفحة الرئيسية وملفاتها، واختبارات DOM للبحث والتحديات والمبادرات والتخزين، ونجح البناء. جرى التحقق آليًا من الروابط المحلية للصفحات الثلاث والـmanifest وأبعاد الأيقونات. تعذّر اختبار Chromium لعدم توفر الملف التنفيذي للمتصفح؛ يجب التحقق من التثبيت والعمل دون اتصال على الجهاز بعد النشر. لم يُشغّل OpenCode Desktop في هذه البيئة، ولم يُنشر المشروع على GitHub بعد.

## ملاحظات تقنية
- جميع المسارات نسبية لتعمل داخل مستودع GitHub Pages فرعي.
- يُشتق إصدار cache من بصمة المحتوى عند البناء. عند التعديل، أعد البناء وارفع dist كاملًا. زر التحديث يظهر عند توفر نسخة جديدة.
- بيانات الإنجاز والأفكار في localStorage فقط، دون حساب أو مزامنة بين الأجهزة. تثبيت التطبيق لا يضمن بقاء البيانات إذا حذف المستخدم بيانات الموقع.
- المحتوى والمبادرات أمثلة تعليمية ولا تمنح شهادات معتمدة.
- `athar-preview.html` نسخة قديمة مستقلة وليست مدخل الموقع أو ملف التسليم؛ استُبعدت من هذه الحزمة لتجنب الالتباس.
